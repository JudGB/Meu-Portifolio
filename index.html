Portifolio

“Run! Doctor Need Help” was a game developed for a school project about blood types, where my group decided to transform the subject into an educational digital game. In the game, the player must dodge obstacles inside a precarious hospital while collecting the correct blood bags for different patients; if the wrong blood type is chosen, the patient dies and the game technically explains the reason based on research conducted by the team. The entire project was developed in the GameMaker Studio 2 engine, with programming, concept design, and artwork all created by me.

“Arrows Running” is a game I developed in 2024 for a competition (game jam) whose objective was to create a simple game themed around weapons such as swords, spears, and bows. That is the premise of the game: you are an arrow traveling as far as possible through the map while the difficulty continuously increases. The game was developed in GameMaker in just one day, with all the artwork, ideas, and programming created entirely by me.

“flapping of wings” was an incomplete game developed in just one week for a programming competition, where the short timeframe led my focus entirely toward engineering and code logic over visual aesthetics. The core of the project is a text-based psychological narrative designed to challenge the player's perception through immersive dialogues and unusual system behaviors. The main programming feature breaks the fourth wall using GML by interacting directly with the user’s operating system; it captures the PC's local username for dynamic AI dialogues and creates a silent persistence file (.temp) to detect if a player is lying about their first time playing. The entire project was developed in the GameMaker engine using GML, focusing heavily on file I/O manipulation and conditional branching logic.

“Morceguinho” was a game developed to put programming and game design concepts into practice, focusing heavily on mechanics and systems. In the game, the player controls a bat exploring procedurally generated caves in search of the best completion times, navigating through dynamic grids that constantly challenge the player's movement and reflexes. The core mechanics include constant falling, flapping wings to stay airborne, and executing dashes through double clicks. The entire project was developed in the GameMaker engine using GML, with the procedural generation code standing out as the biggest development challenge.
