  # Meu Portfólio Profissional (Projeto de Estudos)
</div>
Este repositório contém o código-fonte do meu site pessoal de portfólio. Desenvolvido para consolidar meus conhecimentos em desenvolvimento Front-end, o projeto reúne meus principais links, projetos e informações de contato em uma interface limpa e organizada.


## Sobre o Projeto

Este projeto foi construído **exclusivamente para fins didáticos, prática e estudos**. A proposta foi criar uma página centralizada de apresentação profissional, aplicando conceitos de organização visual, semântica HTML5 e modularização de arquivos de estilo.

O layout foi planejado para carregar rapidamente e ser acessível em qualquer dispositivo, servindo como cartão de visitas digital para a exposição dos meus projetos em evolução.

## Tecnologias Utilizadas

O site foi construído de forma nativa e otimizada utilizando:

* **HTML5:** Estruturação limpa do conteúdo e links de navegação.
* **CSS3:** Estilização visual completa, layout, tipografia e gerenciamento de cores do portfólio.
* **JavaScript:** Scripts criados para adicionar interatividade e dinamismo aos elementos da página.

---

## Aprendizados e Práticas Aplicadas

Durante o desenvolvimento deste portfólio, foquei em praticar:

* **Organização de Pastas:** Separação correta de fontes, scripts e imagens, mantendo a raiz do projeto limpa.
* **Hierarquia Visual:** Uso estratégico de fontes personalizadas para direcionar a atenção do usuário para as partes mais importantes (quem eu sou, meus projetos e contatos).
* **Consistência em Case Sensitivity:** Gerenciamento rigoroso de caminhos (como o arquivo `Style.CSS`), compreendendo a importância de respeitar maiúsculas e minúsculas na web.


## Estrutura de Arquivos

Abaixo está o mapeamento dos arquivos estruturados no repositório:

```text
├── fonts/          # Arquivos de tipografia personalizados do portfólio
├── imagens/        # Logos, fotos de perfil e mídias visuais do site
├── scripts/        # Lógica e comportamento interativo em JavaScript
├── index.html      # Estrutura de marcação principal da página
└── Style.CSS       # Folha de estilo principal (Atenção às maiúsculas!)
```

## Como Executar o Projeto Localmente

Para visualizar e testar o portfólio no seu computador, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/JudGB/Meu-Portifolio
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd Meu-Portifolio
   ```

3. **Abra o arquivo principal:**
   Basta dar um duplo clique no arquivo `index.html` ou utilizar a extensão **Live Server** no seu editor de código (como o VS Code) para ver o site rodando.
